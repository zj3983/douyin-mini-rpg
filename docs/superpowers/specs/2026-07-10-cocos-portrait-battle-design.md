# Cocos 竖屏全屏战斗设计

## 目标

将当前只有空场景层级的 Cocos Web 版本推进为可实际游玩的第一关，验证竖屏横版修仙割草的核心体验：角色踩剑移动、自动释放御剑术、怪物分批出现、魂球自动吸收、关底 Boss 和破关结算。

本阶段只迁移战斗闭环，不迁移抽卡、背包、装备、法宝库和正式登录页。这些页面保留在旧 Web 项目中作为后续迁移参考。

## 画面方向

- 使用竖屏全屏战斗，设计分辨率为 `750 x 1334`，适配手机安全区域。
- 背景覆盖整个可视区域，使用两到三层图片做缓慢视差，地面层与角色脚下高度一致。
- 玩家位于屏幕左侧约 25% 位置，默认高度占屏幕约 30%，敌人从右侧进入。
- 顶部 HUD 只显示境界、生命、法力、魂质进度和 Boss 血条。
- 底部保留贴边半透明导航，不设置摇杆、普通攻击按钮或技能按钮。
- 战斗提示使用短暂浮层，不使用遮挡角色的大标题或卡片。

## 第一关内容

第一关使用现有世界关卡配置：

- 关卡：青苔丘陵。
- 场景主题：雾竹林。
- 地面怪：苔纹狼妖。
- 飞行怪：青翼蛾妖。
- 关底 Boss：竹林守山兽。

普通怪按时间和存活上限生成。达到关卡击杀要求后停止普通刷怪并召唤 Boss；只有击败 Boss 才能破关并进入下一关。

## 核心操作与战斗

玩家点击战斗区域后，角色以固定速度平滑移动到目标位置。连续点击只更新目标点，不重启动画、不瞬移。可移动区域避开顶部 HUD 和底部导航。

角色没有普通攻击，只自动释放本命术“御剑术”。技能流程为：

1. 角色播放短掐诀动作。
2. 飞剑从角色身侧出鞘，沿曲线穿透前方敌人。
3. 飞剑越过最后一个目标后回锋，再次经过敌人时可造成伤害。
4. 命中时播放剑光、受击闪白、轻微顿帧和伤害数字。
5. 技能结束后飞剑回到角色脚下，角色恢复御剑悬浮动作。

飞剑轨迹根据玩家和目标的实时位置计算，近距离敌人不会让剑尖朝地面穿插。技能冷却期间角色持续御剑移动，不前冲。

## 角色与怪物动画

角色使用统一图集管理 `sword_ride`、`hand_seal`、`hurt` 三组动作。第一版不使用旧的整张方形立绘当战斗角色；战斗精灵必须为透明背景序列帧。

怪物使用统一图集管理 `idle`、`move`、`attack`、`hurt`、`death`。地面怪通过身体和腿部的完整序列帧移动，飞行怪通过原图翅膀帧动画飞行，不额外叠加假腿或假翅膀。Boss 使用独立尺寸、攻击前摇和技能警示。

## 掉落与成长

- 普通怪死亡掉落魂球。
- 魂球进入玩家附近范围后自动吸附，不要求角色精确碰撞。
- 魂质满时只增加角色基础攻击、生命和法力，不弹出基础属性卡片。
- 本阶段不触发法宝质变选项；法宝获得与升级继续保留在副本系统中。
- Boss 结算奖励包含灵石、法宝精华和概率副本卷。

## 组件边界

- `PortraitBattleBootstrap`：创建并绑定第一关场景节点，保证构建后可直接运行。
- `BattleInputController`：把触摸/点击转换为安全区域内的移动目标。
- `PlayerController`：只处理平滑移动和御剑悬浮，不处理伤害规则。
- `FlyingSwordSkill`：管理施法节奏、去程与回程轨迹、技能表现事件。
- `BattleRuntimeController`：连接纯规则层、敌人节点、伤害、掉落、Boss 和结算。
- `StageDirector`：加载背景层和当前关卡主题，并在关卡切换时替换资源。
- `EnemySpawner`：按主题和角色类型从对象池生成敌人。
- `BattleHudController`：刷新顶部 HUD、Boss 血条和底部导航显示。

规则计算继续放在 `assets/Scripts/Core`，Cocos 节点和动画只放在 `assets/Scripts/Game`。组件通过事件传递命中、死亡、拾取和结算结果，避免把数值规则复制进动画脚本。

## 数据流

1. 场景启动后读取 `cultivation-design.json`，创建第一关运行时。
2. 关卡导演加载雾竹林背景，生成器按运行时节奏取出怪物节点。
3. 自动技能选择当前有效目标并向规则层提交飞剑路径。
4. 规则层返回命中、伤害和死亡结果，表现层播放对应动画和特效。
5. 死亡敌人回收到对象池并生成魂球；魂球吸收后更新魂质和 HUD。
6. 达到条件后生成 Boss；Boss 死亡后冻结战斗并显示小型结算面板。

## 性能约束

- 角色、怪物、飞剑、魂球、伤害数字和命中特效使用对象池或常驻节点。
- 同角色所有动作使用单张图集和动作配置，不加载大量散图。
- 同屏普通怪上限先设为 18，伤害数字上限 24，短特效上限 16。
- 不使用全屏 DOM、CSS 动画或运行时图片裁切；所有战斗表现由 Cocos 节点完成。
- 手机 Web 目标保持稳定 50 FPS 以上，技能释放时不得出现明显停顿。

## 异常与降级

- 素材加载失败时显示带名称的简洁占位节点，并继续战斗，控制台记录缺失资源路径。
- 对象池耗尽时跳过低优先级伤害数字和余晖，不阻断伤害结算。
- 无有效敌人时飞剑不出鞘，冷却短暂重试。
- 场景配置无效时停留在第一关并显示一行错误提示，不进入空白画面。

## 验证标准

- Node 测试覆盖目标选择、连续点击移动、飞剑去回程穿透、Boss 门槛和魂球吸附规则。
- Cocos 构建检查确认主场景、脚本、资源和 Web 构建产物完整。
- 浏览器以 `390 x 844`、`430 x 932` 两种手机视口试玩，确认人物完整、HUD 不遮挡、底部导航不覆盖角色。
- 自动试玩至少运行三分钟，确认普通怪持续生成、御剑术持续释放、魂球可吸收、Boss 可出现并被击败。
- 本地验证通过后构建 Web Mobile 包，再更新远程 `/game/douyin-mini-rpg/`。

## 非本阶段范围

- 正式账号注册与登录。
- 抽卡、角色碎片、背包、装备和法宝库页面迁移。
- 四个副本及多层撤离玩法迁移。
- 抖音小游戏平台登录、支付、广告和云存档接入。
